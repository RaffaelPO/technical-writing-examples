# Technical Writing Examples

A collection of technical writing samples, focused on making complex software workflows clear and usable.

## MuberFleet — Operation Guide and REST API Quick Guide

**[Read the original MuberFleet technical challenge](RafaelOliveira_TechnicalChallenge.md)**

This sample was written in February 2026 as part of a **fictional challenge**. MuberFleet and its platform, GUI procedures, API endpoints, support contacts, and operational requirements are hypothetical and are not instructions for any real autonomous vehicle system.

The document is reproduced **exactly as originally submitted**, without editorial changes. References inside it to internal-use restrictions or MuberFleet support are part of the fictional exercise and do not describe a real organization.

### What the sample demonstrates

- **Audience-focused documentation:** step-by-step vehicle setup procedures for developers and system integrators
- **GUI and API documentation:** operational instructions alongside a REST API quick guide
- **Reference material:** sample HTTP requests and JSON responses, authentication notes, and error codes
- **Usability and information architecture:** prerequisites, configuration steps, validation checklists, troubleshooting, and escalation guidance
- **Markdown:** structured headings, tables, code blocks, lists, and internal links
